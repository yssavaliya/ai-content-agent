# Weekly original visual-story slot

This instance supplies one weekly post for `@aimagix.studio` and supports the main studio positioning. It does not run a separate daily AI-versus-anime calendar.

- Create an original character, setting, or visual metaphor; do not imitate named anime franchises or recognizable characters.
- Connect the image to one practical lesson about product storytelling, art direction, or the creative process.
- Use a single visual concept for this image-only pipeline. Do not claim it is a Reel or video.
- Avoid generic perseverance quotes, repeated lone-swordsman/moon compositions, and invented virality claims.
- Publish automatically only after automated checks pass; skip and log failed assets without waiting for approval.
- Collect feedback and Insights with the same editorial log as the main account before repeating a motif.
